# Baca Ceria — unduh aplikasi

Aplikasi Android untuk anak SD yang belum lancar membaca: huruf, suku kata, kata,
kalimat, cerita, menebalkan huruf, dan membaca dengan suara.
**Gratis, tanpa iklan, bisa dipakai tanpa internet.**

## Cara memasang

1. Unduh file APK di atas dari HP Android.
2. Buka file-nya. Jika diminta, izinkan **"Instal aplikasi tidak dikenal"**.
3. Ketuk **Pasang**. Versi baru bisa dipasang menimpa versi lama; progres anak tetap ada.
4. Buat profil anak, lalu ikuti tes awal agar anak mulai dari tahap yang tepat.

## Baca Bersuara tanpa kuota

Sekali saja: buka **Setelan HP → Google → Suara → Pengenalan ucapan offline**, lalu
unduh **Bahasa Indonesia**. Izinkan mikrofon saat menu Baca Bersuara dibuka pertama kali.

## Untuk guru: Dasbor Kelas

- **HP anak:** Menu Orang Tua → Laporan → ikon QR "Kirim ke guru".
- **HP guru:** halaman pilih profil → "Saya guru: Dasbor Kelas" → Pindai QR.

## Privasi

Progres anak hanya tersimpan di HP. Aplikasi tidak punya server dan tidak menampilkan iklan.
